# Recipes

The `<name>.md` pages beside this file are generated by `pnpm docs:recipes` from
`examples/recipes/<name>/main.ts`, and every code block in them is type-checked by
`pnpm docs:harness`. Do not edit them by hand — edit the recipe source and regenerate.

**Source convention.** A recipe is one directory, `examples/recipes/<name>/`, whose entry point is
`main.ts`. The file opens with a `/** … */` block comment: its **first line is the page title** and
its remaining paragraphs are the prose. Everything after that comment is the recipe code, emitted as
one fenced `ts` block and capped at 80 lines (`16-docs-harness-and-skill.md` §5). A recipe whose
first line after the comment is `// docs:run` is emitted as `ts run` instead, and the harness
executes it under Node. The generator writes `<name>.md` only — it does not touch this index, so a
new recipe is added to the table below and to the Recipes table in `../../SKILL.md` by hand.
