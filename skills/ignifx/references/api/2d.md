# @ignifx/2d

`@ignifx/2d` public barrel: `Camera2D`, `SpriteRenderer`, `SpriteAnimator`, atlases, `Tilemap`,
sorting layers, pixel-perfect rendering, and parallax (`docs/architecture/00-overview.md` §2).

The package is deliberately empty; Phase 6 of `docs/plan/engineering-plan.md` populates it
with explicit named re-exports (coding standards §4).
